Old Google search

If you are like me and want to get rid of Google's AI overview after every search, you can avoid writing "-ai" everytime by changing the default search engine to http://google.com/search?udm=14&q=%s This will set the search results to the "Web" tab, excluding all ai-focused results.

Set fingerprint in terminal for sudo

If you want to enable the fingerprint to approve sudo requests in terminal, you simply run
  1. fprintd-enroll to activate the fingerprint reader (it is already active if you have set up the fingerprint for unlocking the pc);
  2. sudo pam-auth-update and select "fingerprint" in the list of options;
  3. test it with a generic sudo-command.
warning It looks like this will slow the first login after a boot, because pam is expecting the fingerprint in addition to the password.

Fix GitLab permission denied with ssh keys

  1. Check if ssh is installed
  2. Run ssh-keygen -t rsa -C "email address"
  3. Run eval $(ssh-agent -s)
  4. Run ssh-add 'keyname'
  5. Run cat 'keyname'.pub
  6. Copy the output to the clipboard
  7. Go to Gitlab > Profile > Settings > SSH Keys
  8. Add ney key
  9. Copy the copied key into the "Key" field and then "Add key"
  10. Test connection with ssh -T git@gitlab.com

Mount .vhdx files on Linux

If you would like to read Windows virtual disks from Linux, for example WSL's storage, here are the steps:
  1. Install qemu-nbd (Network Block Device)
    • Ubuntu: sudo apt install qemu-utils
    • Fedora: sudo dnf install qemu-img
    • Arch: sudo pacman -S qemu-base
  2. Enable nbd in kernel with sudo modprobe nbd max_part=8
  3. Attach the .vhdx file to nbd slot with sudo qemu-nbd --connect=/dev/nbd0 /path/to/file.vhdx
  4. Mount the partition in read-only mode: sudo mkdir -p /mnt/vhdx
    sudo mount -o ro /dev/nbd0p1 /mnt/vhdx
To clean everything up you have to:
  1. Unmount with sudo umount /mnt/vhdx
  2. Disconnect with sudo qemu-nbd --disconnect /dev/nbd0
  3. (Optional) Remove kernel module with sudo rmmod nbd
Note If standard unmounting does not work, you can add the flag "-l" to step 1 and call "sudo pkill -9 qemu-nbd" before step 2.
