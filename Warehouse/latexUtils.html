LaTex utilities

Below are some custom commands and package settings that are commonly used (and useful) when writing articles (on numerical analysis).

Custom commands

  • \newcommand{\set}[1]{\left\lbrace #1 \right\rbrace }
  • \newcommand{\abs}[1]{\left|#1\right|}
  • \newcommand{\norm}[1]{\left\|#1\right\|}
  • \newcommand{\quoted}[1]{\textquotedblleft#1"}
  • \renewcommand{\arraystretch}{1.2}

Common packages

  • \usepackage[margin=3cm]{geometry}
  • \usepackage{amsmath, amssymb, amsthm}
  • \usepackage{mathtools, authblk, booktabs, xcolor}
  • \usepackage[bookmarks]{hyperref} with \hypersetup{colorlinks = true,linkcolor = blue,citecolor = red}
